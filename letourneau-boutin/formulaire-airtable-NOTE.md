# Formulaire Airtable — ce qui est fait et le clic qui reste

Créé le 18 août 2026.

## Fait (automatiquement)

- Base Airtable : **« Questionnaire découverte — Létourneau Boutin »** (`appQ72xtDfFJk1QP0`), workspace « My First Workspace ».
- Table **« Réponses »** (`tblMCaaN02Kh0qDpV`) avec les 12 questions finales, dans l'ordre :
  code répondant (choix A–E), rôle, journée type, tâches répétitives, temps par tâche,
  frustrations, retards, temps de réponse client, outils (cases à cocher), 9b outils IA,
  5 heures libérées, idée libre. Le champ « Réf. » est interne (à masquer dans le formulaire).

## À faire par Ugo (≈ 2 minutes — le connecteur ne peut pas publier un formulaire)

1. Ouvrir la base → table « Réponses » → barre des vues → **Form** (créer une vue formulaire).
2. Glisser les questions dans l'ordre 1 → 11 ; **masquer le champ « Réf. »** ; marquer « 1. Votre code répondant » **obligatoire**.
3. Coller le **mot d'introduction** dans la description du formulaire et le **bloc confidentialité** à la fin (textes dans `questionnaire-final.md`).
4. « Share form » → **Create a shareable link** → copier le lien.
5. Remplacer **[LIEN-FORMULAIRE]** dans les 3 brouillons Gmail (Isabelle, Julie, Jennifer) par ce lien, puis envoyer.
6. Test rapide : ouvrir le lien en navigation privée, soumettre une réponse bidon (code E), vérifier qu'elle arrive dans la table, puis la supprimer.

## Rappels confidentialité (Loi 25)

- Le lien est le même pour tout le monde ; l'anonymat vient du **code répondant**.
- Le code part **individuellement**, idéalement vers l'adresse personnelle (voir courriels) — jamais dans un courriel de groupe ni consigné au bureau.
- Détruire les réponses au plus tard 6 mois après la collecte.
